## 🔴 Прогалины паритета (чего у типового комбайна есть, а у нас нет)

| Функция | Риск | Приоритет | Комментарий |
|---|---|---|---|
| **Автопостинг** (по расписанию в СВОИ каналы/группы) | 🟢 низкий | **высокий** | Публикация в свои каналы — безопасно (не спам), востребовано. **Хороший кандидат** — можно сделать без риска. |
| **Инвайтер** (добавление юзеров в группы) | 🔴 высокий | средний | Массовый инвайт = спам/бан, Telegram жёстко лимитирует. Только с осознанным риском + низкие лимиты. |
| **Тегер** (масс-упоминания юзеров) | 🔴 высокий | средний | Пересекается со Story Mentions. Спам-риск. |
| **Авторегер** (регистрация новых аккаунтов) | 🔴 ToS/инфра | низкий | Нужны SIM/SMS-шлюзы (§6). Вне текущего скоупа. |
| **Клоннер** (копирование контента канала) | 🟡 средний | низкий | Копировать посты чужого канала к себе. |
| **Чекер/валидатор** аккаунтов (batch) | 🟢 низкий | средний | Частично покрыт GGR; можно расширить массовой проверкой сессий. |

## Вывод

Наша платформа **сильнее** типового комбайна по ИИ-слою (генерация к цели с базой знаний,
CRM-воронка, кампании-оркестрация, RBAC) — это дифференциатор. Для полного паритета «модуль-в-модуль»
не хватает прежде всего **автопостинга** (безопасно, высокий приоритет) и, с оговорками по риску,
**инвайтера / тегера**.

**Рекомендация:** следующий безопасный модуль для паритета — **Автопостинг** (расписание →
публикация в свои каналы/группы, ИИ-генерация постов к цели). Инвайтер/тегер — только по явному
запросу с пониманием бан-риска.

**Ограничение ресёрча:** конкретные фичи именно DarkSoft из роликов не извлечены (YouTube не
скрейпится). Если нужен точный список DarkSoft — прислать текстом ключевые модули из видео.

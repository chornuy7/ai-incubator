# Тесты приватного API (Python)

Прогон закрытого API Murmex `/api/v1` (доступ по ключу «мозгов», §10.3).
Зависимостей нет — только Python 3 (проверено на 3.13).

## 1. Взять ключ

Ключ приватного API — это **сервисный ключ «мозгов»**, он задан в окружении сервера
(`MURMEX_API_KEY`), а не выпускается в интерфейсе. Возьмите его значение из `.env`
сервера (или у того, кто настраивал прод). Статус «ключ задан» виден в админке →
вкладка **API**.

## 2. Запустить

**Linux / macOS:**
```bash
export MURMEX_API_KEY="aii_live_sk_..."
python3 test_api_v1.py --base https://myrmexgram.ai
```

**Windows (PowerShell):**
```powershell
$env:MURMEX_API_KEY="aii_live_sk_..."
python test_api_v1.py --base https://myrmexgram.ai
```

Локально (dev-сервер): `--base http://localhost:3001`.

## Что проверяется

`health` · доступ без ключа/с кривым ключом → 401 · `/me` (от чьего имени ключ) ·
`/capabilities` (что умеет каждый модуль) · `/mcp` (манифест инструментов) ·
создание цели · список целей · создание кампании · `estimate` (цена/время).

## Флаги

- `--base <url>` — адрес сервера (по умолч. `https://myrmexgram.ai`).
- `--key <ключ>` — вместо `$MURMEX_API_KEY`.
- `--module <ключ>` — модуль для estimate/run (по умолч. `neuro-commenting`).
- `--run` — **реально запустить модуль** (действие по аккаунтам!). Без флага run не выполняется.

Скрипт ничего не удаляет; создаёт тест-цель и тест-кампанию (безвредно). Код возврата
0 — всё прошло, 1 — были падения, 2 — не задан ключ.

# Myrmex — корень

AI-платформа массового управления Telegram-аккаунтами: прогрев, нейрокомментинг, нейрочатинг,
парсинг каналов, автоматизации, биллинг действий.

## Карта проекта

| Где | Что |
|---|---|
| `src/pages/` | экраны панели целиком |
| `src/widgets/` | составные блоки, из которых собираются экраны |
| `src/features/` | пользовательские сценарии |
| `src/shared/`, `src/api/` | переиспользуемые компоненты и клиент HTTP-API → `mem:src/core` |
| `server/*.js` | роуты и доменные модули (`accountHealth`, `campaigns`, `channels`…) |
| `server/lib/` | доменное ядро, по файлу на понятие → `mem:server/core` |
| `server/modules/` | система модулей задач — ровно три файла: `registry`, `routes`, `workers` |
| `server/mcp/` | сервер MCP и дескрипторы модулей |
| `supabase/` | `schema.sql` и ~50 миграций Postgres — здесь живут все данные платформы |
| `server/data/` | копия тех же данных в JSON, только для тестов и локального запуска; в `.gitignore` |
| `server/__tests__/` | ~140 файлов тестов, перечислены поимённо в `package.json` |
| `api-tests/` | **второй, независимый набор тестов**: Python, приватный `/api/v1` по ключу оркестратора. Командой `npm test` НЕ запускается |
| `scripts/` | `sync.mjs`, скрипты миграций, генераторы документации |
| `deploy/` | `deploy.sh`, конфиг nginx, systemd-юнит — файлы выката на боевой сервер |
| `docs/CONTRACT-*.md` | контракты подсистем: state machine аккаунта, lease каналов, RBAC, логи |

## Инварианты проекта

- **Аккаунт ≠ Профиль.** Аккаунт — управляемый Telegram-бот (`/api/accounts`). Профиль —
  человек, пользователь панели (`/api/me`). Разные права, лимиты и таблицы. Самая частая и
  дорогая ошибка в обсуждениях требований.
- **Данные живут в общей базе.** Файлы в `server/data/` — не второе хранилище, а фолбэк для
  тестов и локального запуска. Переключатель и правило владельца — `mem:server/core`.
- **Язык:** комментарии и документация по-русски, содержимое MCP — только по-английски
  (проверяется тестом). Подробности в `mem:conventions`.

## Две памяти, и они не смешиваются

- **Файловая память Claude** (`~/.claude/projects/<проект>/memory/`) — решения, договорённости
  и всё, чего нет в коде и в истории git. Вне репозитория, у каждого своя, в PR не видна.
- **Заметки Serena** (`.serena/memories/`, вот эти) — код и устройство проекта. В репозитории,
  общие для команды, ревьюятся в PR как обычный markdown.

## Процесс работы над задачей

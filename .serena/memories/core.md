# Myrmex — корень

AI-платформа массового управления Telegram-аккаунтами: прогрев, нейрокомментинг, нейрочатинг,
парсинг каналов, автоматизации, биллинг действий.

## Карта верхнего уровня

| Путь | Что |
|---|---|
| `src/` | фронт, React/Vite, слои FSD → `mem:src/core` |
| `server/` | бэкенд, Node/Express, ESM → `mem:server/core` |
| `supabase/` | `schema.sql` и миграции — настоящее хранилище |
| `server/data/` | локальный фолбэк хранилища, в `.gitignore`, НЕ источник истины |
| `scripts/` | `sync.mjs`, миграции, генераторы |
| `docs/CONTRACT-*.md` | контракты: state machine, lease, RBAC, логи действий и аудита |

## Инварианты проекта

- **Аккаунт ≠ Профиль.** Аккаунт — управляемый бот (`/api/accounts`). Профиль — человек,
  пользователь панели (`/api/me`). Разные сущности, права и лимиты. Самая частая и дорогая
  ошибка в обсуждениях требований.
- **Хранилище одно — общая база.** Файлы в `server/data/` это не второе хранилище, а фолбэк
  для локального запуска и тестов. Подробности и правило владельца — `mem:server/core`.
- **Язык:** комментарии и документация по-русски, содержимое MCP — только по-английски
  (проверяется тестом). Подробности в `mem:conventions`.
